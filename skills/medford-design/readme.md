# Medford Design System

Источник: экспортированный Design System артефакт (`_ds_manifest.json`, `_ds_bundle.js`,
`Canvas.dc.html` — рабочие файлы claude.ai, не редактировать вручную). Файлы `tokens/*.css`,
`styles.css` и этот readme реконструированы из `_ds_manifest.json` для использования в обычных
статичных HTML-документах (статьи, JSON-LD-страницы), где нет доступа к React/SPA-рендерингу.

Это единственный источник цветов, шрифтов и отступов для HTML-статей и инфографики Medford —
он заменяет любые ранее придуманные палитры (например, старую пару навy `#102C4C`/стальной
`#2C5F8A`, использованную до появления этого дизайн-кита).

## Цвета

- **Основной (primary):** `--cyan-500` `#00BCDA` — акцентные элементы, ссылки, левая граница H2.
- **Акцент (gold):** `--gold-500` `#FDC500` — **только промо/акции**, не использовать в обычном
  тексте статьи.
- **Нейтрали (ink):** `--ink-900…50` — от почти чёрного текста (`--text-strong`) до светлого фона
  страницы (`--surface-page` = `--ink-50`).
- **Семантика:** `--success-500` (зелёный, `#1FA971`), `--warning-500` (янтарный, `#F59E0B`),
  `--danger-500` (красный, `#E23B3B`), `--info-500` = `--cyan-500`. У каждого есть светлый фон
  `*-50` для карточек/капсул.
- **Поверхности:** `--surface-card` (белый), `--surface-sunken` (светло-голубой, `#EEF6FB`),
  `--surface-invert` (`--ink-900`).

## Шрифты

- **Normalidad Wide** (Regular/Bold) — заголовки (`--font-display`, токены `--fs-h1…h4`,
  `--fs-display-*`).
- **Normalidad Text** (Light/Medium) — основной текст (`--font-text`, `--fs-body*`).
- Фолбэк — Montserrat, затем `system-ui`. Файлы шрифтов лежат в `assets/fonts/`, подключены через
  `tokens/fonts.css` (относительные пути `../assets/fonts/...`).
- Для самодостаточного HTML-файла (единый файл без внешних зависимостей) шрифты и/или изображения
  можно инлайнить как `data:` URI — так делались предыдущие статьи проекта.

## Отступы, радиусы, тени

`tokens/spacing.css`: шкала `--space-0…24` (4px база), радиусы `--radius-xs…2xl` и `--radius-pill`,
тени `--shadow-xs…lg` + `--shadow-cyan` (акцентная тень под primary-кнопки), длительности
переходов `--dur-fast/base/slow`.

## Как применять к статьям (docx → HTML)

Проект генерирует HTML-статьи из docx (см. корневой `CLAUDE.md`, раздел «Формат вывода»).
Соответствие прежних самодельных классов новым токенам:

| Назначение | Токены |
|---|---|
| Заголовок H1/H2 (шрифт) | `font-family: var(--font-display)`, цвет `var(--text-strong)` |
| Основной текст | `font-family: var(--font-text)`, цвет `var(--text-body)` |
| Левая граница H2 | `border-left: 4px solid var(--color-primary)` |
| Капсула-ответ под H2 (была мятная `#DFF4F4`) | фон `var(--info-50)`, левая граница `var(--info-500)` |
| Предупреждение/не путать (было красным `#FAE9E9`) | фон `var(--danger-50)`, левая граница `var(--danger-500)` |
| Заголовок таблицы (был navy `#102C4C`) | фон `var(--ink-900)`, текст `var(--white)` |
| Зебра-строки таблицы | `var(--surface-sunken)` |
| Блок «Об авторе» | фон `var(--surface-sunken)`, `border-radius: var(--radius-md)` |
| Карточки/фигуры (изображения, инфографика) | `border-radius: var(--radius-sm)`, `border: 1px solid var(--border-default)` |
| Ссылки | `color: var(--text-link)` |

Правило дизайн-системы: **без градиентов и текстур**, только плоские заливки; жёлтый (`gold`)
не использовать вне промо-контекста.

## Компоненты и ассеты (для полноценных страниц сайта, не для статей)

`_ds_manifest.json` также описывает React-компоненты (`Header`, `Footer`, `CatalogSidebar`,
`ProductCard`, `CategoryCard`, `Badge`, `Button`, `Card`, `Tag`, формы) и стартовую точку страницы
каталога — они относятся к продакшен-сайту medford.ru (SPA), не к статичным HTML-статьям этого
проекта. Иконки и изображения оборудования лежат в `assets/icons/`, `assets/equipment/`,
`assets/categories/`.
