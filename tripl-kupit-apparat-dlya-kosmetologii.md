## 1. Как читать таблицы

- **Субъект → предикат → объект** — ядро триплета.
- **Слой внедрения** — где триплет должен присутствовать, чтобы он «сработал» (методика требует трёх слоёв: видимый текст статьи/страницы, JSON-LD, внешний авторитетный источник).
- **Частота в SERP** — у скольких выдач/конкурентов встречается признак: задаёт приоритет (8+/10 — обязательно внедрять; редкое — точка отстройки).
- **Статус факта** — подтверждено данными SERP / требует оговорки / не фабриковать.

Частоты считаны по трём запросам кластера (Google AI-режим + Яндекс Обзор ИИ + Топ + похожие запросы/вопросы). Числовые цены и «топы» взяты из выдачи дословно и требуют пометки «ориентировочно» с датой актуализации при публикации.

## 5. Семантические слои воронки (проверка по методике tripl)

- **Лексика:** сущность «аппарат для косметологии» / «купить» — в Title, H1, паспорт-абзаце.
- **Семантика:** одна страница = одна сущность. Кластер расщепляется на отдельные URL с перелинковкой: «аппараты для косметологии» (обзор категорий) ↔ «профессиональные аппараты» (для салонов/клиник) ↔ «купить аппарат» (коммерческая страница с ценой/гарантией). Запрос «купить» — коммерческий, ведёт на страницу с прайсом, а не на обзорную статью.
- **Сущности (граф, sameAs):** бренды/платформы из SERP — Lumenis (STELLAR M22), Fraxel, Divine pro; технологии — HIFU, RF, IPL/BBL, Nd:YAG. Для JSON-LD связывать через `Product`/`Offer` и `Organization`.
- **Пассажи:** TL;DR + капсулы-ответы на вопросные H2 (см. раздел 6), HTML-таблица категорий (раздел 2) дублирует инфографику.
- **Мультимодальность:** уместна инфографика-**определитель** «задача → технология → аппарат» (дерево решений), которого нет в тексте дословно; таблицу категорий картинкой не дублировать.

## 8. Что НЕ фабриковать

- Точные цены и сроки без пометки «ориентировочно» и даты — брать только дословно из SERP как ориентир.
- Долю эффективности «технология X лучше Y на N %» — в выдаче таких чисел нет.
- Медицинские результаты/показания сверх того, что дословно указано в обзорах ИИ.
- Рейтинги и «топ-N» подавать как чужие подборки со ссылкой, а не как собственную оценку без данных.
- Статус «официальный дистрибьютор/сертификат» конкретного бренда — только при наличии подтверждающего документа.
