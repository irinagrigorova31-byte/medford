## Товарные триплеты (субъект → предикат → объект)

Каталог: 2 позиции, детальных характеристик в брифе минимум.

- Стойка СМПП-02 Medtrade → является → медицинской приборной тележкой
- Стойка СМПП-01 Medtrade → является → медицинской приборной тележкой
- Приборная тележка → размещает → видеопроцессор, источник света, монитор, аспиратор
- Приборная тележка → обеспечивает → перемещение комплекса между кабинетами

## Категорийные триплеты (из обзора ИИ SERP)

AI Overview богатый — основа для категорийных пассажей.

- Эндоскопическая тележка → служит для → размещения и транспортировки компонентов системы
- Тележка → изготавливается из → стали с порошковым покрытием / алюминия / ударопрочного пластика
- Тележка → имеет → многоуровневую структуру (обычно 3–6 полок)
- Тележка → оснащена → поворотными колёсами с резиновым ободом
- Два колеса по диагонали → снабжены → тормозом для фиксации
- Тележка → включает → кабель-менеджмент (держатели и направляющие)
- Тележка → может нести → розеточные блоки, мониторные кронштейны, ящики, держатели эндоскопов

## Вопросные триплеты (PAA / похожие запросы)

- Что входит в эндоскопическую стойку? → процессор, источник света, монитор, аспиратор, аксессуары
- Что такое эндоскопия простыми словами? → осмотр полостей эндоскопом (смежная тема, отдельный URL)
- В чём разница между эндоскопией и лапароскопией? → смежная тема, не расфокусировать эту страницу
- Сколько стоит эндоскопическая стойка? → цену в брифе не давать

## Что НЕ фабриковать

- Характеристики СМПП-01/СМПП-02 (число полок, нагрузка, материал, габариты) — в брифе только тип.
- Цены на стойки.
- РУ Росздравнадзора конкретной модели — упоминать как требование, не утверждать наличие.
- Совместимость с конкретными брендами эндоскопов без данных.
- Модели STEINMANN/КРОНТ как товары каталога — это примеры из SERP, не позиции Медфорд.
